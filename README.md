# SIGNAL//STATION

An original browser-based retro desktop simulation for the CodeRush Senior coding challenge.

Live site: https://menukarisith.github.io/signal-station/

## Concept

It is October 1998. A coastal storm has disrupted the regular radio route. The player tunes three lighthouse transmissions, locks their decoded messages, then broadcasts a safe passage.

## Run

Open `index.html` in a browser or deploy the three source files to any static host. No dependencies, server, account, or external data are needed.

## Controls

- Drag the frequency dial or use Left/Right Arrow keys.
- When a carrier is clear, use **Lock Signal** or Enter.
- Decode all three signals and broadcast the route.
- Use **Sound: Off** in the header to enable original synthesized receiver sounds.
- Use Reset to replay the experience.

## Files

- `index.html` — semantic interface structure
- `style.css` — original responsive retro desktop visual system
- `polish.css` and `desktop.css` — hardware details and desktop-session layout
- `app.js` — deterministic tuning puzzle and UI state
